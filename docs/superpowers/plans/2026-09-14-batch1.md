Tambah ke `src/core/money/money.ts`:
```ts
export function parseDecimalToMinor(raw: unknown): bigint | null {
  const s = typeof raw === "number" ? String(raw) : raw;
  if (typeof s !== "string") return null;
  const t = s.trim().replace(",", ".");
  const m = /^(\d+)(?:\.(\d{1,2}))?$/.exec(t);
  if (!m) return null;
  const minor = BigInt(m[1]) * 100n + BigInt((m[2] ?? "0").padEnd(2, "0"));
  return minor > 0n ? minor : null;
}
```
CATATAN: `minor > 0n → null` berarti NOL ditolak — benar untuk amount pembayaran/harga (domain menuntut positif, konsisten guard B2 `>0`); JANGAN pakai helper ini untuk kuantitas/diskon-nol yang sah (qty tetap Number; discount nol = lewati/tetap 0n via jalur existing, jangan ubah perilakunya).
